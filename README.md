# SmashAP

## Цель проекта
**SmashAP** — это образовательная платформа нового поколения для подготовки к экзаменам Advanced Placement (AP). Сервис предоставляет доступ к структурированным курсам, интерактивным тестам с автоматической проверкой, детальной статистике прогресса и удобной системе оплаты, помогая студентам эффективно готовиться к экзаменам и достигать высоких результатов.

В рамках проекта была поставлена задача разработать полноценное веб-приложение с нуля, включая серверную часть, базу данных, пользовательский интерфейс и развертывание на production-сервере.

## Моя цель как разработчика
Реализовать масштабируемую и надежную платформу для онлайн-образования, взяв на себя полный цикл разработки:
- Спроектировать и разработать бэкенд с многослойной REST API архитектурой.
- Создать удобный и функциональный фронтенд с современным стеком технологий.
- Настроить и администрировать production-инфраструктуру для обеспечения бесперебойной работы.
- Интегрировать платежную систему и сервисы уведомлений для полной автоматизации процессов.

## Архитектура проекта
Проект построен по принципу клиент-серверной архитектуры с четким разделением на три ключевых слоя:

1.  **Frontend (React + TypeScript)**
    - Приложение структурировано по методологии **Feature-Sliced Design (FSD)**, что обеспечивает высокую масштабируемость и поддерживаемость кода.
    - Управление состоянием реализовано через **Redux Toolkit** и **RTK Query** для эффективного кэширования и инвалидации данных.
    - Реализовано более 15 адаптивных страниц, стилизованных под макет из **Webflow**.

2.  **Backend (Java + Spring Boot)**
    - Серверная часть построена на **Spring Boot** и представляет собой многослойный REST API, разделенный на 20+ функциональных модулей (курсы, тесты, зачисления, заказы, статистика и др.).
    - Реализована надежная система безопасности с **JWT-аутентификацией**, ролевой моделью доступа и ограничением количества запросов (**Rate Limiting**) через **Bucket4j** и **Redis**.
    - Вся логика взаимодействия с API документирована с помощью **Swagger/OpenAPI**.

3.  **Database (PostgreSQL)**
    - Спроектирована нормализованная схема базы данных, содержащая 20+ таблиц со сложными связями.
    - Версионирование схемы и контроль миграций выполняются с помощью **Flyway** (реализовано 34 миграции).
    - Для повышения производительности добавлено более 15 индексов, оптимизирующих выполнение запросов.

## Основные технологии
### Backend
- **Java**, **Spring Boot** — основа серверной логики
- **PostgreSQL**, **Redis** — основная БД и кэширование/ограничение запросов
- **Flyway** — миграции базы данных
- **Bucket4j**, **JWT** — безопасность и rate limiting
- **PayPro Global API**, **Hostinger SMTP** — интеграция платежей и email-уведомлений

### Frontend
- **React 19**, **TypeScript** — основа пользовательского интерфейса
- **Redux Toolkit**, **RTK Query** — управление состоянием и работа с API
- **React Hook Form**, **Zod** — валидация форм
- **KaTeX**, **Markdown** — отображение математических формул и форматированного текста

### DevOps & Infrastructure
- **Docker**, **Nginx** — контейнеризация и веб-сервер
- **Ubuntu (VPS)** — production-окружение
- **Systemd**, **SSL (Let's Encrypt)** — автозапуск сервисов и безопасность
- **DBeaver** — администрирование БД

## Реализованные задачи
### Backend разработка
- Спроектирована многослойная REST API архитектура с 20+ модулями (`courses`, `tests`, `enrollments`, `orders`, `statistics` и др.)
- Реализована JWT-аутентификация с role-based authorization и rate limiting через Bucket4j + Redis
- Разработана система тестирования с тремя типами тестов и автоматическим расчетом статистики
- Интегрирована платежная система PayPro Global с обработкой webhooks и автоматическим созданием enrollments
- Настроена email-рассылка через Hostinger SMTP и система уведомлений
- Создана API документация с Swagger/OpenAPI

### Database Administration
- Спроектирована нормализованная схема БД с 20+ таблицами и сложными связями
- Реализовано 34 Flyway миграции для версионирования схемы
- Добавлено 15+ индексов для оптимизации запросов
- Выполнялось ручное управление через DBeaver: анализ данных, миграция production данных, мониторинг производительности

### Frontend разработка
- Реализована Feature-Sliced Design (FSD) архитектура с Redux Toolkit и RTK Query
- Разработано 15+ страниц с адаптивной версткой (Webflow)
- Создана система тестирования с countdown таймерами, валидацией форм (React Hook Form + Zod)
- Внедрена поддержка Markdown с математическими формулами (KaTeX) и code highlighting
- Настроено кэширование API запросов с автоматической инвалидацией и JWT token refresh

### DevOps и развертывание
- Развернул production-инфраструктуру на VPS (Ubuntu): настройка Nginx reverse proxy, SSL-сертификаты, маршрутизация frontend/backend
- Настроил автозапуск Spring Boot через systemd с автоматическим восстановлением при сбоях
- Организовал процесс деплоя: Git pull, Gradle build, перезапуск сервисов без простоя
- Администрировал PostgreSQL: управление пользователями, ролями, правами доступа, подключение DBeaver
- Сопровождал Flyway миграции в production, восстанавливал целостность данных после инцидентов
- Настроил безопасное хранение конфигурации через environment-файлы и SSH-доступ к серверу
- Диагностировал production-инциденты через логи systemd, Nginx, Spring Boot
- Управлял доменом, DNS-записями и HTTPS-конфигурацией
